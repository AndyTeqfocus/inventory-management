Factory Inventory Management System

Architecture overview · Vue 3 frontend · FastAPI backend · JSON mock data (no database) · ~8,400 lines

Request flow

1 User changes a filter in FilterBar.vue → shared refs in useFilters update  2 The active view calls api.js, which maps filters to query params  3 FastAPI route runs apply_filters / filter_by_month over the in-memory lists  4 Result is validated by a Pydantic model and returned as JSON  5 View stores raw rows in refs; KPIs and charts are computed properties

Layers

Frontendclient/
  • Vue 3 Composition API, Vite dev server on port 3000, vue-router with 6 views
  • Custom SVG charts and CSS Grid; no component library
  • i18n via useI18n with locales/en.js and ja.js
  • Filter state is a module-level singleton, so every view sees the same 4 filters
Backendserver/
  • Single-file FastAPI app, 14 read-only GET routes, Swagger at /docs
  • Managed with uv (pyproject.toml, uv.lock); run with uv run python main.py
  • CORS wide open for local dev
  • Quarter filters expand to month lists via QUARTER_MAP
Dataserver/data/
  • Seven JSON files loaded by mock_data.py at import time
  • No persistence: nothing writes back, restarting resets state
  • generate_data.py rebuilds the fixtures
Claude Code setup.claude/
  • Subagents: vue-expert (mandatory for .vue edits), code-reviewer, security-auditor
  • Slash commands: /start, /stop, /test, /optimize, branch helpers
  • Skill: backend-api-test for pytest work
  • MCP: Playwright and GitHub servers in .mcp.json; a PostToolUse hook logs tool calls to logs/

Things worth knowing before you change code

  • The API base URL is hard-coded in api.js; there is no Vite proxy.
  • Inventory rows have no date, so the Time Period filter cannot apply to them.
  • Use stable keys in v-for (sku, month), never the index.
  • Revenue goals are fixed: $800K per month, $9.6M YTD across all months.
  • The repo and any fork are public; client/.npmrc and the ignored lockfile keep private registries out of commits.
